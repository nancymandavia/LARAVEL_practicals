Laravel Routing Practical: Home, About, Contact

Files included:
- routes/web.php
- resources/views/home.blade.php
- resources/views/about.blade.php
- resources/views/contact.blade.php

How to use:
1. Create or open a Laravel project.
2. Copy routes/web.php into your project's routes/web.php (or merge the routes).
3. Copy the three Blade files into your project's resources/views/ folder.
4. From the Laravel project directory, run: php artisan serve
5. Visit:
   /         -> Home
   /about    -> About
   /contact  -> Contact

Note: This ZIP contains the practical files, not a complete Laravel installation.
